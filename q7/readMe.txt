For Windows:

Click "Run Anyway": In the SmartScreen pop-up window, click More info and then click Run anyway. Once run once or twice on a machine, Windows may stop flagging it if it's in a controlled environment.

Exclude the Folder in Windows Defender: If Windows Defender antivirus blocks the file from being created or executed locally, add your project's dist/ folder to the Exclusions list in Windows Security settings.
